## 🎯 Overview

A modern, high-performance developer portfolio showcasing technical expertise, personal projects, and professional contact information. Built with **React + Vite** for optimal performance, featuring smooth animations with **Framer Motion**, responsive design with **Tailwind CSS**, and comprehensive multilingual support.

The portfolio emphasizes:
- Clean, professional design
- Smooth user experience
- Fast loading times
- Accessibility
- SEO optimization

## ✨ Features

### 🎨 **Design & UI**
- **Glass morphism cards** with backdrop blur effects
- **Custom cursor glow** that follows mouse movement
- **Floating particles** background animation
- **Smooth parallax scrolling** with opacity transforms
- **Gradient accents** on hover states
- **3D tilt effects** on project cards (rotateX/rotateY)
- **Animated skill bars** with percentage indicators
- **Realistic code preview** mockups in project cards
- **Elegant typography** with tracking and leading optimization

### 🌓 **Theme System**
- **Dark mode** (default) with deep space background
- **Light mode** with clean, professional white theme
- **System mode** that follows OS preferences
- **Persistent theme storage** in localStorage
- **Smooth theme transitions** without flickering

### 🌐 **Multilingual Support**
- **English** (primary)
- **Uzbek** (native language)
- **Russian** (regional)
- **Language persistence** in localStorage
- **Complete translations** for all UI elements
- **RTL-ready** structure

### 🖱️ **Interactive Elements**
- **Custom mouse follower** with spring physics
- **Hover animations** on all cards
- **Smooth scroll** between sections
- **Animated navigation menu** with hamburger
- **Form validation** with visual feedback
- **Success/error toasts** with icons
- **Loading states** on form submission

### 📱 **Responsive Design**
- **Mobile-first** approach
- **Breakpoints**: sm, md, lg, xl, 2xl
- **Collapsible navigation** on mobile
- **Touch-friendly** hover states
- **Optimized images** for all devices
- **Fluid typography** scaling

### 🚀 **Performance**
- **Vite** for lightning-fast builds
- **Code splitting** by route
- **Lazy loading** for below-fold content
- **Optimized animations** with useSpring
- **Debounced scroll** handlers
- **Memoized components** to prevent re-renders

### 🔧 **Developer Experience**
- **ESLint** configuration
- **Prettier** code formatting
- **Hot module replacement** (HMR)
- **Environment variables** support
- **Git hooks** with Husky (optional)
